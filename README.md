# NesyCollage
A simple, free and open source tool for creating A4, print-ready photo collages. Based on angular 22.

Create layouts using horizontal and vertical splits, drag and zoom your photos inside each frame, and resize the splits to get the exact composition you want.

## Run
```bash
pnpm start
```

## Features
- Contextual photo library (Select files)
- A4-ready layouts — designed with printing in mind
- Horizontal & vertical splits
- Drag photos within their frames
- Zoom photos to get the perfect crop
- Resize splits to customize your layout
- Save & Load your project (saves to default download folder, loads from anywhere)

## Performance Disclaimer
Don't expect this to be optimized. This project was largely vibe-coded and I didn't spend any time optimizing the code.

Depending on the number and resolution of your photos, you may encounter some performance limitations.
That said, it works, and I think the simplicity is one of its strengths.

## Why this exists
I wanted a simple way to create printable photo collages.

I looked around for existing free and open-source solutions, but couldn't find anything that combined simplicity, ease of use, and this particular set of features.
